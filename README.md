### ◈ LAB (EXPERIMENTS & LESSONS)

* **`EXP-001` RAG Scoring Consistency**: RAG retrieval introduced noise into scoring rubrics. *Lesson*: Prompt engineering and structured output schemas matter more than injecting raw unstructured context.
* **`EXP-002` Local LLM Tail Latency**: Average time-to-first-token was low, but disk indexing caused latency spikes. *Lesson*: P99 tail latency determines real-time UX quality, not average latency.
* **`EXP-003` Mobile Sockets vs Polling**: Persistent WebSocket connections dropped frequently on mobile OS backgrounding. *Lesson*: Exponential backoff polling is more reliable over mobile cellular networks.
